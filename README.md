# Google Docs Clone 📝

A modern, full-stack document editor inspired by Google Docs, built with Next.js, React, TypeScript, and Tailwind CSS. Create, edit, and manage documents through a clean and responsive user interface.

## ✨ Features

- 📝 **Rich Text Editor** – Create and format documents using Tiptap.
- 📄 **Document Management** – Create, access, and manage documents.
- 🎨 **Modern UI** – Clean, responsive, and user-friendly interface.
- 🤖 **AI Integration** – AI-powered functionality through API routes.
- 🔌 **REST API** – Backend API endpoints for document operations.
- ⚡ **Next.js** – Optimized full-stack application architecture.
- 🗄️ **Database Integration** – Prisma ORM for database operations.

## 🛠️ Tech Stack

**Frontend:**
- Next.js

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Itsmeuntulmubeen/Google-docx.git
```

### 2. Navigate to the Project

```bash
cd Google-docx
```

### 3. Install Dependencies

```bash
bun install
```

### 4. Configure Environment Variables

Create a `.env` file and add the environment variables required by your project.

### 5. Run the Development Server

```bash
bun run dev
```

### 6. Open in Browser

Visit:

```text
http://localhost:3000
```
